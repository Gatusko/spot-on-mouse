# Privacy Policy — Spot on Mouse

_Last updated: November 17, 2026_

Spot on Mouse does not collect, store, transmit, or share any personal data.

## What the app does on your device

- **Cursor position.** The app reads the mouse cursor position, using a
  standard Windows low-level mouse hook, only to draw the highlight spot at
  that position. Cursor positions are never recorded, saved, or sent anywhere.
  Keyboard input is never read.
- **Settings.** The app saves your display settings (spot colour, size, shape,
  whether the spot is enabled, and saved profiles) in a local configuration
  file on your computer. This file never leaves your device.
  - Microsoft Store version: the file is kept in the app's private storage and
    is removed automatically when you uninstall the app.
  - Standalone `.exe` from GitHub: the file is kept at
    `%APPDATA%\spot-on-mouse\config.json` and can be deleted by hand.

## Network access

The app makes no network connections. It contains no analytics, telemetry,
advertising, or crash reporting.

## Third parties

No data is shared with any third party, because no data is collected.

## Children

The app does not collect any data from anyone, including children.

## Changes

If this policy changes, the updated version will be published in this file and
on the app's Microsoft Store page.
